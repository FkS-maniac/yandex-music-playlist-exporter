1. Ссылка или iframe плейлиста

Яндекс не разрешает браузеру обращаться к API напрямую. Для экспорта укажите адрес своего Cloudflare Worker — инструкция есть в README.

HTML iframe обрабатывается как текст — код страницы не запускается.

Укажите базовый адрес Worker без пути, например https://playlist-proxy.example.workers.dev
